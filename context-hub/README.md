## ⚙️ Quick Setup & API Keys Guide

1. **Open Settings**: Click `⚙ API Keys` in the top right header.
2. **Enter Key**:
   - **OpenRouter**: Get key at [openrouter.ai/keys](https://openrouter.ai/keys)
   - **Groq**: Get key at [console.groq.com/keys](https://console.groq.com/keys)
   - **Anthropic**: Get key at [console.anthropic.com](https://console.anthropic.com)
   - **Ollama Local**: Run `ollama run qwen2.5-coder:32b` on your machine.
3. **Verify Key**: Click `🧪 Verify` to test key connectivity.
4. **Permanent Storage**: Verified keys are saved automatically to `localStorage` (`cf_keys`).
